### 1.6 画布几何换算（outfit-layout.js 同步修改）

背景：`outfit-layout.js` 坐标系单位 rpx、原点为 `.composition` 左上角（`outfit-layout.js:1-28` 头注释）；`CANVAS`/`BASE_SIZES`/`DEFAULT_LAYOUT` 当前为 650×410 全宽数值（`outfit-layout.js:32-51`），CSS 兜底值 `index.wxss:160-198` 与之一致。

换算公式（保持比例缩放，不重新摆放）：
```
内容宽 = 750 − 页面左右边距×2
画布宽 W = 内容宽 − 左栏宽 − 栏间距
比例 s = W / 650
画布高 H = round(410 × s)
新 CANVAS  = { width: W, height: H }
新 BASE_SIZES  = { w: round(w×s), h: round(h×s) }          // 每槽
新 DEFAULT_LAYOUT = { x: round(x×s), y: round(y×s), scale: 1, zIndex: 不变 }
```
推荐数值（左栏 210rpx、栏间距 16rpx、页面边距 24rpx）：
```
内容宽 = 750 − 48 = 702；W = 702 − 210 − 16 = 476；s = 476/650 = 0.732；H = 300

CANVAS = { width: 476, height: 300 }

BASE_SIZES:
  hat:    { width: 95,  height: 67  }
  top:    { width: 168, height: 127 }
  bottom: { width: 176, height: 114 }
  shoes:  { width: 145, height: 56  }
  bag:    { width: 107, height: 104 }

DEFAULT_LAYOUT:
  hat:    { x: 238, y: 35,  scale: 1, zIndex: 8  }
  top:    { x: 238, y: 118, scale: 1, zIndex: 7  }
  bottom: { x: 238, y: 211, scale: 1, zIndex: 5  }
  shoes:  { x: 245, y: 271, scale: 1, zIndex: 6  }
  bag:    { x: 346, y: 185, scale: 1, zIndex: 10 }
```
- 验算：默认 y 均未触发 `clampToCanvas`（`outfit-layout.js:73-94`）夹取（shoes 最大允许 y=272，默认 271），全部图元完整落在 476×300 内。
- `clampToCanvas`/`moveLayer`/`resetSlot`/`toRenderLayer` 因引用 CANVAS/BASE_SIZES/DEFAULT_LAYOUT 常量，换数后自动正确，无需改函数逻辑；同步更新 `outfit-layout.js:11-28` 头注释中的容器推导说明。
- 同步修改 CSS 兜底 `.layer-hat/.layer-top/.layer-bottom/.layer-shoes/.layer-bag`（`index.wxss:160-198`）为换算后数值，保持兜底与数据一致。
- 可选参数（如需更大画布，缩小左栏即可，比例 s 同步变化）：
  | 左栏宽 | 栏间距 | W | s | H |
  | --- | --- | --- | --- | --- |
  | 210 | 16 | 476 | 0.732 | 300（推荐） |
  | 190 | 16 | 496 | 0.763 | 313 |
  | 180 | 14 | 508 | 0.782 | 320 |
- 垂直余量可选：若真机感觉拥挤，可只把 `CANVAS.height` 提到 320（默认 y/zIndex/BASE_SIZES 不动，仅加宽容 clamp 边界），不改变图元排布。
- 测试影响：`outfit-layout.test.js` / `outfit-layout-preserve.test.js`（`tests/`）基于常量断言，改数后需同步更新期望值；测试意图（clamp/层级/重置/保真）不变。

- 分类（单选必填）：5 列网格（`grid-template-columns: repeat(5, minmax(0,1fr))`，gap 12rpx），格高 112rpx、圆角 16rpx，图标 26rpx + 标签 22rpx 纵排（`item-upload.wxss:46-51`）。选中 = 品牌粉边 + 浅粉底 + 品牌粉字图标。

- 字段间距：组内 `margin-top: 28rpx`；组间卡片间距 22rpx。

### 3.4 横向溢出防控

- 规则 1：所有多选胶囊容器必须 `flex-wrap: wrap`，任何情况不得产生横向滚动（季节 4 枚、风格 4 枚在当前宽度必然放得下，且换行可接受）。
- 规则 2：网格一律 `minmax(0, 1fr)`，禁止固定宽列导致溢出。
- 规则 3：half 栏（`flex:1`、gap 18rpx）内控件 min-width 不设大值；厚度 compact 胶囊 min-width 72rpx。
- 规则 4：文本类（名称、备注、渠道）均单行/文本域自适应，禁止 `white-space: nowrap` 于宽文本。

### 3.5 保存 / 下一步按钮层级

- 底部操作行（`item-upload.wxml:127-132`）：两按钮等宽（`flex:1`、gap 18rpx、高 88rpx、圆角 44rpx）。
  - 次 = 「取消」（step 2）/「返回修改」（step 3）：浅粉底 + 粉边 + 粉字。
  - 主 = 「下一步：确认」（step 2）/「确认保存」（step 3）：渐变粉 + 白字 + 600 + 阴影；`loading`/`disabled` 时降透明度（`item-upload.wxss:71` 已实现）。

## 4. 全局视觉规则

依据：项目视觉方向约束 + 现有代码（`app.wxss`、`wardrobe.wxss`、`home/index.wxss`、各页）。以下为 Round 1.5 统一基线，供穿搭页、上传页、编辑页及后续页面共用。

### 4.1 间距体系

- 页面左右边距：穿搭页 24rpx（两栏需要）；上传/编辑等表单页 28rpx。
- 区块间距（卡与卡之间纵向）：20–24rpx。
- 卡片内边距：24–28rpx（表单卡 28、画布卡 16、槽位卡 8–12）。
- 组间距（标题到内容 / 字段到字段）：14–28rpx。
- 控件间：12–18rpx（网格内 gap 12–20）。
- 图与文字间：8–14rpx。
- 底部安全区：`calc(env(safe-area-inset-bottom) + 36rpx)`（沿用 `index.wxss:454-456`）。

### 4.2 标题层级

| 层级 | 字号/字重 | 颜色 | 用途 |
| --- | --- | --- | --- |
| 页面主标题 | 44rpx / 700 | `#3f2d30` | 「试穿」等页首标题（居中场景） |
| 区块标题 | 28rpx / 650 | `#453e41` | 「可选入库衣物」「基础信息」「单品属性」 |
| 面板标题 | 24rpx / 600 | `#5b4346` | 「已选衣物」「试衣搭配画板」 |
| 字段标签 | 24rpx / 500 | `#6d6367` | 表单字段名 |
| 正文 / 卡名 | 24–26rpx | `#443c40` | 单品名、说明 |
| 说明 / 提示 | 20–22rpx | `#968b90` / `#a58b90` | 辅助文案、hint |
| 弱注 / 角标 | 16–20rpx | `#a48e91` | 槽标签、计数 |

### 4.3 圆角层级

- 大卡（区块级）：32rpx。
- 表单卡 / 画布卡：28rpx。
- 网格单品卡：24rpx；槽位小卡：18rpx。
- 输入框 / 格选：16–18rpx。
- 主/次按钮：42–45rpx（胶囊）；胶囊 chip：30–34rpx。
- 圆形元素（图标、徽标、头像）：50%。

### 4.4 边框与阴影规则

- 卡片默认边框：`2rpx solid #f1ded8`（表单控件用 `#eee2e2`）；弱虚线仅用于空态/上传区（`#e4cdd0`/`#f0c4d0`）。
- 禁止大量粉色边框（只允许选中态与主 CTA 出现粉边）。
- 阴影：柔和低强度，`0 12–18rpx 30–40rpx rgba(190, 110, 125, .06–.10)`；仅大卡与主按钮使用，胶囊/chip/文字按钮不加阴影。
- 主按钮阴影：`0 12rpx 24rpx rgba(232, 81, 120, .16)`。

### 4.5 品牌粉使用规则

- 色板：
  - 品牌粉主色（CTA 填充/选中边/强调数字）：`#ef5d80`（渐变色 `#f47c9a → #ed557c`）。
  - 品牌粉文字/图标（非填充）：`#d9536f` / `#e75e7d`。
  - 浅粉底：`#fff0f3`；浅粉边框：`#f2c5cf`（强）`#f5d6dd`（弱）。
  - 页面底 `#fff9f8`；卡底白 `#ffffff`；正文近黑 `#3f3538`；次文字 `#8a7d82`。
- 使用边界：品牌粉只用于——主按钮、选中态、链接/文字按钮、关键数字、图标强调。禁止用于——正文、大范围背景铺色、所有卡片边框、失控的粉色文字（「文字全粉」）。
- 选中态规范（全局统一）：未选中 = 白底 + `#eee2e2` 边 + `#655c60` 字；选中 = 品牌粉边 `2rpx #f2829d` + 浅粉底 `#fff0f3` + 品牌粉字/图标；可选加 ✓ 徽标（品牌粉底白勾）仅用于需要区分「多选计数」的卡片。单选胶囊与多选胶囊选中态视觉一致（单选不需徽标）。
- 状态色：成功 `#69a559`、警告 `#d58a56`、危险文字 `#b45a69`；危险操作用弱化次按钮 + 二次确认，不与主按钮抢焦点（`小衣橱-子页面统一视觉规范-V1.md` §5）。

### 4.6 按钮层级

- 主按钮（primary）：渐变粉底 + 白字 600，高 88–92rpx、圆角 44–46rpx、阴影；用于唯一主操作（保存、确认、下一步）。
- 次按钮（secondary/soft）：浅粉底 + 粉边 + 粉字，高 82–88rpx、圆角 41–44rpx；用于取消、返回修改、重置、更换图片等第二操作。
- 文字按钮（text）：无底透明、品牌粉字 22–24rpx；用于换一套、重试、去衣橱上传、全部等内联动作。
- 危险按钮（cancel/delete 弱化）：浅灰底 `#f6f0f1` + 灰字，或复用次按钮样式；必须二次确认。
- 尺寸铁律：可点区域 ≥ 60rpx（次要） / ≥ 84rpx（主要），保证触控（`小衣橱-子页面统一视觉规范-V1.md` §11）。
